`share` compresses a Source into the URL fragment, so a link is this program's artifact — and until
now that link previewed as nothing. GOLEM//Console gets its own favicon (the Console prompt, which
is the whole control grammar), the icon sizes a browser tab, an iOS home screen and an install
prompt each ask for, a description written from the reader's side, and an Open Graph / Twitter card
showing a session beside the live register readout and the Terminal. `theme-color` matches the Theme
the pre-paint script paints, so the browser chrome no longer flashes a different colour.
