GOLEM//Console installs, and it runs with the network off. A web app manifest makes the machine
installable under its own mark, and a service worker precaches the whole shell on the first visit, so
the second one opens with no network and you can write assembly, assemble it, and drive a run from
the Console exactly as before. The program you were last editing is still in the editor: your Source
has always lived in this browser and neither installing nor an outage touches it. Installed, it opens
standalone on the same near-black the page paints.

A new version never takes over a session in progress — which matters more here than anywhere else on
the deck, because a running Machine, its Terminal and its Registers exist nowhere but the tab. A new
build installs quietly behind the one you are using and waits: the run carries on, the Clock keeps
its rate, and nothing changes until you open the program again or take the offer that appears under
the header.
